# Abartılı Otobüs Bekleyicisi

## Dünyanın En Ciddi, En Bilimsel ve En Gereksiz Otobüs Bekleme Simülatörü

Bu proje, otobüs beklerken yaşanan derin varoluşsal krizi bilimsel titizlikle simüle etmek için geliştirilmiştir. 

**Önemli Uyarı:** Bu yazılım otobüsü çağırmaz. Otobüsün gelmesini sağlamaz. Hatta otobüsün gelme ihtimalini azaltabilir. Kullanım sorumluluğu size aittir. Biz sadece izleriz.

### Nasıl Çalışır?

```bash
python otobus_bekleyicisi.py
```

Program 5 dakika boyunca (aslen 2.5 saniye) otobüsün neden gelmediğine dair son derece ciddi bahaneler ve felsefi notlar üretir. Sonunda otobüsün gelmediğini resmi olarak açıklar.

### Bilimsel Temeller

- 47 farklı otobüs durağında test edilmiştir.
- 0 otobüs gelmiştir.
- 1 kedi şahit olmuştur ama ifade vermemiştir.
- Araştırma ekibi 3 çay içmiş, 1'i soğumuştur.

### Özellikler

- Gerçekten çalışır.
- Gerçekten otobüs gelmez.
- Felsefe üreti (sıfır).
- Kayyum onaylıdır (değildir, mahkeme karışmış).

### Katkıda Bulunma

Pull request açabilirsiniz ama otobüs gelmeyecek. Bahane ekleyebilirsiniz. Felsefe ekleyebilirsiniz. Otobüs ekleyemezsiniz.

### Lisans

Bu yazılım "Otobüs Gelmez Lisansı" altında dağıtılmaktadır. İstediğiniz gibi kullanabilirsiniz, yeter ki otobüs beklerken şikayet etmeyin. Şikayet ederseniz de etmeyin, zaten gelmeyecek.
